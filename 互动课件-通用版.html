    题库管理

    这个课件本体只负责「教学功能」（翻题、遮罩、聚光灯、标注、激光笔、计时、投票）。 题目内容全部放在「题库」里 —— 换一份资料时，在这里导入新题库即可，无需改动任何代码。 导入的内容会保存在本机浏览器中，下次打开自动恢复。
    把文件拖到这里，或点击选择文件
    支持：.docx（Word 试卷）、.json（题库）、.txt / .md（纯文本题目）
    导入后这里会显示识别到的题目预览，确认无误再点「应用」。
    直接把 Word 里的文字整段粘进来即可，格式类似：
    1. 观察孩子的天赋在哪里，然后往那些方向鼓励他们。 → A. what B. where … 答案：B 解析：……
    识别结果会显示在这里。
    当前题库的 JSON。可以直接改，改完点「应用」。
    这是一个可选的拖拽巩固模块（例如把连词拖进句子）。
    每行填：选项标签 | 正确答案 | 句子，其中正确答案用 A/B/C… 指代上面词池里的编号。
    题库 JSON 结构（字段全部可选，除了 stemHtml 和 choices）：
    { "meta": { "title": "…", "subtitle": "…", "seconds": 30 }, "questions": [ { "n": 1, "topic": "名词性从句 · 宾从", "stemHtml": "题干 HTML，挖空写成 ___", "choices": [ { "l": "A", "t": "what" } ], "answer": "B", "explain": { "title": "【答案】 B", "ruleHtml": "解析", "rule2": "易错点", "translate": "译文" } } ], "extension": { "enabled": true, "topic": "拖拽巩固", "stemHtml": "把正确的选项拖入空格", "pool": [ { "w": "A", "label": "Although" } ], "items": [ { "text": "他很穷，但他很快乐。", "correct": "A" } ] } }

    纯文本识别规则：题号开头（1. / 1、 / 1．）， 选项行以 A. / A、 / A． / (A) 开头， 答案：X 识别为正确答案，解析：… / 译文：… 会被识别为解析与译文。
